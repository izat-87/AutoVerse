# 🏎️ AutoVerse — Автомобильный портал премиум-класса

![AutoVerse](https://img.shields.io/badge/version-1.0.0-gold)
![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

**AutoVerse** — это современный, премиальный автомобильный обзорный портал, позволяющий пользователям исследовать самые известные автомобили мира: их историю, характеристики, цены, наличие и многое другое.

---

## ✨ Возможности

- 🚗 **30+ легендарных автомобилей** с полной информацией
- 🏷️ **25 мировых брендов** (Lamborghini, Ferrari, Bugatti, Porsche, Rolls-Royce и др.)
- 📂 **10 категорий** (гиперкары, суперкары, люксовые, электромобили и др.)
- 🔍 **Полноценный поиск** по названию, бренду, категории, году, цене, стране
- 🎛️ **Многофункциональные фильтры** (цена, скорость, год, двигатель, наличие)
- 💰 **Цены в 3 валютах**: USD, EUR, национальная валюта производителя
- 📍 **Статус наличия**: в продаже / у дилеров / ограниченная серия / снят с производства
- 🛒 **Кнопки «Где купить»** — ссылки на официальные сайты производителей и дилеров
- ❤️ **Избранное** с сохранением в localStorage
- 🎬 **Видеообзоры** и фотогалереи с лайтбоксом
- 📊 **Гиды**: самые быстрые, дорогие, редкие автомобили, история индустрии
- 📰 **Новости** автомобильной индустрии
- 📱 **Полная адаптивность** (компьютер, планшет, смартфон)
- 🎨 **Премиальный дизайн**: тёмная тема, glassmorphism, плавные анимации

## 🛠️ Технологии

| Технология | Назначение |
|------------|------------|
| **HTML5** | Структура и семантика |
| **CSS3** | Дизайн-система, анимации, адаптивность |

## 📂 Структура проекта

```
├── index.html              # Точка входа (SPA)
├── css/                    # 6 модульных файлов стилей
│   ├── reset.css           # Сброс стилей
│   ├── base.css            # Дизайн-система (CSS-переменные)
│   ├── layout.css          # Шапка, футер, поиск
│   ├── components.css      # Переиспользуемые компоненты
│   ├── pages.css           # Стили страниц
│   └── responsive.css      # Адаптивность
├── js/
│   ├── data/               # Данные (бренды, авто, категории, гиды, новости)
│   ├── utils/              # Утилиты (форматирование, storage)
│   ├── components/         # UI-компоненты (карточки, фильтры, поиск)

│   ├── router.js           # Hash-роутер
│   └── app.js              # Точка входа приложения
```

## 🚀 Быстрый старт

### Вариант 1: Просто открыть в браузере
```bash
# Откройте index.html в любом современном браузере
start index.html
```

### Вариант 2: Через локальный сервер
```bash
# Используя npx (требуется Node.js)
npx serve .

# Или через Python
python -m http.server 8080
```

## 🌍 Публикация на GitHub Pages

### Способ 1: Через веб-интерфейс GitHub
1. Создайте новый репозиторий на [github.com](https://github.com)
2. Загрузите все файлы проекта
3. Откройте **Settings → Pages**
4. В разделе **Branch** выберите `main` и папку `/root`
5. Нажмите **Save**
6. Сайт будет доступен по адресу: `https://ваш-логин.github.io/имя-репозитория/`

### Способ 2: Через командную строку (Git CLI)
```bash
# 1. Инициализация репозитория
git init
git add .
git commit -m "Initial commit: AutoVerse premium automotive portal"

# 2. Создайте репозиторий на GitHub, затем:
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
git branch -M main
git push -u origin main

# 3. В GitHub: Settings → Pages → Deploy from branch → main → /root → Save
```

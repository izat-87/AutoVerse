# 📦 Ресурсы для AutoVerse

Этот файл содержит список ресурсов, которые можно скачать для улучшения сайта.

## 🖼️ Фотографии автомобилей (бесплатные стоки)

| Ресурс | URL | Описание |
|--------|-----|----------|
| **Unsplash** | https://unsplash.com | Бесплатные фото высокого качества |
| **Pexels** | https://www.pexels.com | Бесплатные фото и видео |
| **Pixabay** | https://pixabay.com | Бесплатные фото без лицензии |
| **Wikimedia Commons** | https://commons.wikimedia.org | Свободные изображения |

### Как заменить изображения
1. Скачайте фото нужного автомобиля
2. Сохраните в папку `assets/img/cars/`
3. Обновите поле `image` в `js/data/cars.js`

## 🚀 Быстрая публикация

### GitHub Pages (бесплатно)
1. Создайте репозиторий на GitHub
2. Загрузите все файлы
3. Settings → Pages → Branch: main → /root → Save

### Netlify (бесплатно, без Git)
1. Зайдите на https://app.netlify.com/drop
2. Перетащите папку проекта
3. Сайт опубликован мгновенно

## 📝 Примечание

Все изображения на сайте генерируются автоматически (SVG) и не требуют скачивания. Для замены на реальные фотографии используйте ресурсы выше.
